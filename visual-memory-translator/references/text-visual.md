# Text Visual Translation / 文本隐喻转译

当输入是句子、金句、概念或标题、而没有参考照片时走此路径。目标仍是编辑设计页，不是金句配图、信息图或完整绘本。

核心：**句子是概念，画面是一个隐喻，不是把文字画成故事。**

---

## Trigger

- 用户没上传图，但给了可转译的句子/概念。
- 用户说「文本转译」「做成一张卡」「把这句话做成视觉」。
- 用户给的图只是情绪底图、与句子无关时，仍按 text 处理，不把底图当记忆原图。

默认：

```yaml
input_mode: text
preview_mode: skip
style_mode: editorial_metaphor_card
layout_mode: large_whitespace_small_art
original_display_mode: translation_only
text_mode: user_text
whitespace_level: very_high
ratio: 3:4          # 手机分享可改为 9:16
```

---

## Distill first

生成前先压缩信息，不必向用户汇报：

1. **保留原句**（默认）。不要改写成鸡汤，不要加标题党。
2. 抽出 **一个** 可画的张力：加码 vs 配重、降耗 vs 下坡、静音 vs 继续开会。
3. 只选 **一个** 视觉隐喻。禁止为每个分句各画一个场景。
4. 指定 1 个强调词（加粗/下划线/强调色），其余保持克制。

---

## Card structure

推荐结构（自上而下，大量呼吸）：

1. 原句，1–4 行。允许一次强调。
2. 一个小型视觉隐喻，约占画面 15%–30%。
3. 可选 1 个微量批注或色条，不是装饰。

原则：

- 文字是主体之一，但画面不能变成纯排版海报。
- 隐喻必须能在去掉文字后仍可被部分理解。
- 留白是内容。不要用底图照片、城市夜景、雨窗、bokeh 去填空。

---

## Metaphor language

优先：天平、路径、容器、开关、层叠色块、单一器物、一条线的状态变化。

避免：

- 把隐喻画成完整情节（三人在旷野加班、一整场会议）
- 小红书金句卡：毛玻璃照片 + 圆角白卡片
- PPT / 信息图 / 图标矩阵
- 3D 卡通吉祥物、emoji 风、贴纸包
- 为「有画面」而增加无关人物

---

## Color and type

- 2–4 色：黑/深灰 + 纸色 + **一个**强调色。强调色只用于一句或一个物件。
- 字体层级清楚：正文 / 一句 punchline。不要手写满页。
- 可使用细线、下划线、色条；不要花边、印章堆、撕纸相框。

---

## Optional 4-way preview

仅当用户要「先看方向」时：

给出最多 4 个差异明显的隐喻，而不是 6 种绘画风格。例如：

1. 器物隐喻（天平、油表、开关）
2. 路径/斜率
3. 极简色块关系
4. 档案卡/备忘录语气

选号后从原句重建，不放大预览格。
