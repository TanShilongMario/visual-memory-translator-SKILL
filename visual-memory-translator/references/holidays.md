# Holiday Limited Layer / 节日限定

节日限定是叠在既有风格之上的**薄层**，不是新滤镜、不是节日海报。只改变少量颜色、一句文字、1–3 个微图形；不得覆盖全局美学。

日期用**对话当天的公历日期**（不要用照片 EXIF 去假装拍摄日）。窗口为节日当天及前后各 1 天。

---

## Mode

```yaml
holiday_mode: auto    # 默认：窗口内高概率启用
# force               # 用户点名某个节日
# skip                # 用户关闭
holiday_id: auto      # 或 qixi / christmas / ...
```

关闭口令：`不用节日限定` / `不要节日` / `holiday_mode: skip`  
强制口令：`用七夕` / `圣诞节限定` / `holiday_mode: force`

### auto 何时启用

窗口内**默认启用**（高概率 = 默认开，而不是掷骰子）。仅在下列情况跳过：

- 用户已 skip
- 画面明显不宜（丧仪、病房、严肃纪实新闻）
- 节日主题会**虚构关系**（例如单人照却画成情侣）
- 已是 `extreme` 抽象且再加符号会变装饰

窗口内但主题不够贴时：仍可启用，但只用 **low** 强度（一色或一个符号），不要上满套。

### 预览宫格

节日窗口内：6 格中约 4–5 格带薄层，留 1–2 格无节日，方便用户选干净版。回复里用一句说明，不必单独追问：

> 今天是七夕前后，部分方向会带一层极淡的节日痕迹；不想要可以说「不用节日限定」。

---

## Detect

1. 取今天日期。  
2. 按用户语言/地区优先匹配节日：中文 → 中国（及共用农历节日）；日文 → 日本；英文默认美/西历，但仍识别春节、中秋、七夕。  
3. 农历节日必须先换算**当年**公历，再套 ±1 天。不要写死某一年的日期。  
4. 西历可移动节日同样按**当年规则**计算，不要写死日期：复活节、感恩节、母亲节、父亲节。  
5. 日本七夕是**公历 7 月 7 日**；中国七夕是**农历七月初七**。二者不是同一天。  
6. 多节日重叠时只选一个：用户点名 > 用户语言主历 > 更适合画面的那个。  
7. 节日层**不表示**照片拍摄于该日；禁止伪造日期印章为「今天」。

## Intensity

由画面决定，不由节日热度决定。

| 强度 | 何时 | 做法 |
|------|------|------|
| `high` | 画面与节日叙事同向（七夕双人照、圣诞家庭、中秋团圆桌） | 1 个强调色 + 1 句短文 + 1–3 个主题微图形 |
| `medium` | 有人物或生活感，但不是节日场景 | 强调色或 1–2 个微图形，文案可极短或沿用普通诗句 |
| `low` | 风景、建筑、食物、抽象 | 只偏移 1 个点缀色，或 1 个几乎看不见的符号 |
| `off` | skip 条件 | 完全不加 |

硬限制：

- 不加人、不改成情侣、不改服装变节日装。  
- 不用满版红金、雪花暴、爱心雨、圣诞老人、灯笼串、电商促销字。  
- 微图形仍算在全局 1–3 个配额里，不是额外再堆一层。  
- 原图配色仍是主色；节日色只做点缀。

## Motif kits

每个 kit 最多用其中 1–2 项，不要全上。

### 中国 / 共用农历

| id | 规则 | 点缀色 | 可用符号 | 文案语气 |
|----|------|--------|----------|----------|
| `new_year_day` | 公历 1-1 | 朱砂一点 | 细横线、小小「元」 | 开始、留白 |
| `spring_festival` | 农历 1-1，窗口含除夕 | 沉红、暖金一点 | 门的抽象线、一枚印章形 | 年、归、灯，不喊「恭喜发财」 |
| `lantern` | 农历 1-15 | 暖黄 | 一个极简灯形 | 圆、夜 |
| `qingming` | 清明（约 4-4/4-5） | 灰绿 | 一枝细线 | 更静，不画坟墓 |
| `duanwu` | 农历 5-5 | 艾绿、浅朱 | 舟的一条弧线 | 水、岸 |
| `qixi` | 农历 7-7 | 墨、暮色、一点胭脂 | **红线**、喜鹊剪影、两颗星 | 相会、银河；双人照才用情爱主题 |
| `mid_autumn` | 农历 8-15 | 月白、淡金 | 一个不完整的圆 | 圆、缺 |
| `chongyang` | 农历 9-9 | 菊黄一点 | 山的一条线 | 登、远 |
| `national_day_cn` | 10-1 | 少用红；可一点朱 | 几乎只用色，不用旗 | 避免宣传画 |

**七夕专项**：双人/情侣照 → `high`：红线可轻绕构图，喜鹊最多一只或一对极简剪影，短句偏含蓄。单人/风景/建筑 → `low`：一颗星或一根细红线，**不要**补出第二个人。

### 日本

| id | 规则 | 备注 |
|----|------|------|
| `ganjitsu` | 1-1 | 与元旦合并，语气更静 |
| `setsubun` | 约 2-3 | 低强度；不要鬼面具 |
| `hinamatsuri` | 3-3 | 淡桃一点；不要人偶阵 |

### 美国 / 西历

可移动节日按当年计算，禁止写死某年日期。

| id | 规则 | 点缀色 | 可用符号 | 避免 |
|----|------|--------|----------|------|
| `valentine` | 2-14 | 沉红一点 | 一条线、不是心形雨 | 丘比特、粉红暴 |
| `easter` | **西方复活节**：春分（3-21）后第一个满月之后的星期日 | 卵壳白、浅金、嫩芽绿一点 | 一个不闭合的卵形、一枝新叶 | 兔子卡通、彩蛋堆、十字架宗教海报 |
| `mothers_day` | 五月第二个星期日 | 淡粉一点 | 一朵极简花形或一枝线 | 康乃馨爆款、贺卡堆字 |
| `fathers_day` | 六月第三个星期日 | 暖灰、一点褐 | 一条稳的水平线 | 领带/啤酒广告 |
| `independence_us` | 7-4 | 少用国旗三色 | 几乎只偏色 | 旗帜、烟花海报 |
| `halloween` | 10-31 | 墨、一点橙 | 一个不规则形 | 南瓜脸、恐怖堆砌 |
| `thanksgiving` | **美国**：十一月第四个星期四。加拿大感恩节不自动套用，除非用户明显是加境或点名 | 暖褐、麦色 | 一枝线、一张空桌的抽象边 | 火鸡卡通、丰收堆砌、家庭团圆海报 |
| `christmas` | 12-25 | 冷杉绿、一点暖金 | 一枝松针、一颗星 | 圣诞老人、礼物堆、雪花满屏 |
| `new_year_eve` | 12-31 | 同元旦 | 一条地平线 | 倒计时海报 |

复活节默认用西方（格里高利）算法；只有用户明确说东正教时才改。画面有聚餐、家庭、餐桌时感恩节可用 `medium`/`high`；风景建筑只用偏色。

韩国 `seollal` / `chuseok` 分别并入春节、中秋 kit，按用户语言微调文字。

## Prompt injection

节日启用时，插在 prompt 的「文字 / 微图形 / 色彩」之后：

1. `holiday_id` + 强度  
2. 只用 kit 中列出的 1–2 个符号  
3. 明确禁止海报化与多余人物  
4. 原图事实不变  

回复不必解释整个节日故事。一句即可。
