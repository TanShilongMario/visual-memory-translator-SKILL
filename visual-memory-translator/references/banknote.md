# Commemorative Banknote / 纪念纸币

把一次经历发行成一张**虚构纪念券**。上半是铺满的现实照片，下半是货币转译。密度接近真钞（雕版、底纹、面值、冠字），但必须是样张，不是可流通假币。

两种可直接点名的模式（也是 `style_mode`）：

| 用户说法 | style_mode | 下半 |
|----------|------------|------|
| 纸币样张 / 纪念钞样张 | `banknote_specimen` | 图录里平放的一张券 |
| 纸币实景 / 手持纪念钞 / 实景取样 | `banknote_in_situ` | 手持该券，背景为同一现场 |

点名即用。只说「纸币 / 纪念钞」而未指定样张或实景时，按这次需求选更合适的一种，**不要**用「有人必须实景、风景必须样张」的固定分流。

```yaml
original_display_mode: split_top_bottom
layout_mode: split_editorial
holiday_mode: skip
```

---

## Page

- 整页竖构图（默认 3:4）。上下硬切，`clean_cut`，不要胶带、撕纸、手账。
- **上半（约 45%–52%）**：原图**铺满**，可裁切以适配横向中心；保持摄影质感。不要白边、不要相框。
- **下半（约 48%–55%）**：只执行当前点名的那一种模式。

---

## Modes

### `banknote_specimen` — 纸币样张

下半是图录/样张台：暖或冷灰纸面，一张横长纪念券平放或微微倾斜（0°–4°）。可有极浅接触影。券四周露出纸台，不要铺满下半。

适合看清全票面、边饰和雕版层次。

### `banknote_in_situ` — 纸币实景

下半是一张**现场拍照**：一只手（或两指）捏着这张纪念券，对焦在纸币上；背景是**同一张真实照片的场景**，略虚、同光线、同天气。像把刚印好的纪念钞拿到原址取样。

- 只出现手/前臂，不新增大脸人物。
- 纸币必须可读：面值、主景、底纹仍在。
- 背景不得换成另一个地方。

适合强调「这张券被拿到现场对照过」。两种模式都可用于人像、旅行、建筑或风景。

## Banknote density（趋近真钞）

横券约 2:1 至 19:9。票面应像真钞那样信息满、层次满，而不是极简插画卡：

必须有：

1. 完整装饰边与角花  
2. 吉洛歇 / 细密底纹 / 玫瑰线  
3. 主景雕版（见下）  
4. 四角或双侧面值（大数字 + 小写）  
5. 从这张图长出的币名与一行发行语（禁止套用固定词库）  
6. 两组冠字/编号（形态像真钞，内容从图生成，不反复 `NO. 001`）  
7. 微缩文字带、安全线或透明窗之一  

可再选 1–2 项：水印位、对印标记、光变油墨条、副景（从原图再抽一个元素）。

色彩：从原图抽 3–6 色，做成凹版套色（单主色 + 1–2 辅色），允许真钞式的细密套印，禁止彩虹炫光和加密货币风。

## 主景提炼

抽象度 **medium–high**：像凹版，不像照片复印，也不像空的线稿。

| 类型 | 留下 | 删掉 |
|------|------|------|
| 人物 | 姿态、发型、眼镜/帽檐、服装结构；3/4 或侧面雕版头像 | 皮肤毛孔、完整五官写实、第二套服装 |
| 双人 | 两人同在主景或主+副，人数与原图一致 | 补出伴侣、改成官方伟人像 |
| 风景 | 岸线/山脊/地平线 + 一层细纹（水波、林冠） | 完整风景画、旅游明信片天空 |
| 建筑 | 立面轴线、拱、塔、桥的铜版结构 | 玻璃幕墙照片、全部窗户画清 |

人像在此风格允许「雕版肖像」，这是对全局「禁止完整肖像画」的唯一例外：必须是排线凹版，不能是上色写实脸。

## 票面文案（先读图，再开印）

文案必须来自**这一张图**的主体、动作、地貌、材质和情绪，禁止把 `MEMORY` / `SPECIMEN` / `100` / `贰` 当默认套餐。

生成前先内部提炼（不必向用户逐项汇报）：

1. 这张图最值得「发行」的一件事（指向对岸的屋、潮水、并肩、一座桥……）  
2. 语言：招牌、文字、建筑与服饰线索；不确定就用中性词，**不写真国名**  
3. 币名：2–12 字，像一个只存在于这张图里的发行机构或地名残片  
4. 发行语：一行，8–16 字，含蓄，不解释照片、不鸡汤  
5. 面值：选一个与**这张图的尺度或关系**相称的数字，并给出对应大写；理由每次不同  
6. 微缩字：可重复发行语或币名的碎片，不要印真实法条  

| 文案位 | 要求 |
|--------|------|
| 币名 | 从图长出，如溪谷、岸线、某类屋顶；不要每张都叫 MEMORY |
| 面值 | 数字 + 大写；人数、山、海都只是可能线索，不是公式 |
| 发行语 | 一句与画面有隐性关系的短句 |
| 冠字 | 两组，字母数字混合，避免真钞格式，也避免永远 `NO. 001` |
| 样张记 | 需要防伪提示时用「样张」或 `SPECIMEN`，不要占据主标题 |

禁止：CNY、USD、EUR、JPY、人民币、Federal Reserve、中国人民银行、真钞冠字格式、固定诗性数字清单。

未知地点、日期、人名时仍不虚构具体事实；用抽象但**从图来的**词，而不是万能 `FIELD NOTE`。

---

## Avoid

- 复制任何流通钞的精确版式  
- 加密货币、游戏金币、红包  
- 把下半做成第二张原图 + 滤镜  
- 手持模式露出新的完整人脸  
- 节日符号默认叠在底纹上（此风格 `holiday_mode: skip`）
