# Style Preview Contact Sheet

在用户未指定风格时，先把同一张原始照片转译为一张可选的宫格预览图。这是「视觉试衣间」，不是最终作品。

## Trigger and size

- `preview_mode: auto`：无风格指令时生成；已指定风格时跳过。
- `preview_mode: force`：即使用户提到风格，仍先出候选变体。
- `preview_mode: skip`：直达成品。
- `preview_count`：`4 | 6 | 9`；默认 `6`。对应 2×2、2×3、3×3。

## Candidate curation

1. 先根据原图类型、主体结构和情绪筛选适配风格，不做无关风格大全。
2. 候选之间至少在三个维度上有明显差异：原图是否可见、媒介语言、版式关系、抽象度、叙事隐喻。
3. 不得只换色、换纹理或套滤镜。每格都应该像一个独立的艺术指导方案。
4. 尽量覆盖四类视觉语言：绘画/线条、几何/抽象、材料/光学、编辑/档案。
5. 不选与原图结构冲突的模式：无可靠景深时不强行分层贴纸；无道路/动线时不强行地图札记。

默认 6 格的参考结构（按图像适配性替换，不固定排名）：

1. 极简线稿水彩
2. 极致抽象极简
3. 分层贴纸重组或圆润粗线色块
4. 展览票/档案卡编辑
5. 长虹玻璃/材料转译
6. 邮票记忆/地图札记/结构解构中最适合的一种

## Contact-sheet image rules

- 生成**一张图**，内含精确的 4、6 或 9 个等尺寸单元格。
- 所有格使用同一张原始照片、同一主体身份、同一核心姿态/场景，只改变转译语言。
- 统一使用暖米白编辑底板与窄间距，不让宫格本身变成花哨海报。
- 每格只放一个序号：`01`–`09`；位于左上或左下的安全留白区，小而清楚。
- 图内不放风格名、解释、长文、品牌、水印或伪造的地点/日期。
- 预览可降低细节，但每格必须足以判断媒介、版式、留白与抽象度。

## Prompt contract

在生图 prompt 中明确写出：

1. 这是基于输入照片的 style exploration contact sheet，不是多个不同场景。
2. 精确网格数与阅读顺序（从左到右、从上到下）。
3. 逐格说明 `01`–`09` 的视觉语言，但要求图中只渲染编号。
4. 锁定主体身份、姿态、地貌/建筑与天气，禁止加人、加道具、改场景。
5. 要求各格有明显区分，但整张图保持统一的艺术出版质感。

## Reply contract

出图后的回复使用简短清单：

```text
01 风格名 — 这张图为什么适合它
02 风格名 — …
```

结尾只说：「回复编号出高清成品；也可说‘再换一组’或‘融合 02 和 05’。」

## Final regeneration

- 将选中格仅当作创意方向，不当作像素源。
- 将原始照片重新作为 edit target/reference，重建完整成品 prompt。
- 恢复用户要求的最终比例、文字和高细节；不保留宫格边框或编号。
- 若用户选择融合，使一个风格主导版式/媒介，另一个只提供 1–2 个特征，避免风格混浊。
