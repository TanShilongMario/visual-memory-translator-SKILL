# Quality Checklist, Failure Recovery & Safety

---

## Quality Checklist

生成前或生成后检查：

### Style preview

- [ ] 未指定风格时先出 4/6/9 格预览；默认为 6 格
- [ ] 宫格数量与 2×2 / 2×3 / 3×3 布局准确，顺序清楚
- [ ] 各格保持同一主体/场景，风格差异不是换色或滤镜
- [ ] 图内只有 `01`–`09` 编号，无风格名、长文、品牌或水印
- [ ] 编号选择后从原图高清重生成，没有放大预览单格

### Composition

- [ ] 视觉中心明确  
- [ ] 留白足够  
- [ ] 版式不是机械模板  
- [ ] 原图与转译存在明确关系  

### Original image

- [ ] 原图身份和叙事未被误改  
- [ ] 裁切合理  
- [ ] 原图区域仍具摄影感  

### Translation

- [ ] 已明显简化，不是完整重画  
- [ ] 保留最重要的视觉记忆  
- [ ] 抽象程度符合参数  

### Style

- [ ] 风格准确；极简规则未被风格破坏  
- [ ] 色彩来自原图；无无关装饰  

### Layered sticker template

- [ ] 仅提取可从原图可靠识别的 2–3 层；未补造遮挡内容
- [ ] **是 2–3 张可分开的贴纸**，不是一张异形大贴纸
- [ ] 主体、中景、远景尺度有明确层级，且没有重复主体
- [ ] 白边统一，阴影为无或极浅；整体不像贴纸包或手账
- [ ] 贴纸组未超过画面 40%，页面至少约 50% 留白

### Rounded monoline template

- [ ] 线条统一粗细、圆头圆角，无排线和多重描边
- [ ] 人物姿态、服装结构与配饰未被可爱化改写
- [ ] 色块默认 1–3 个，绝不超过 4 个；均为单色、无渐变
- [ ] 主体和色块保持视觉岛尺度，没有铺满页面

### Portrait translation

- [ ] 转译不是完整肖像画；五官被大幅省略
- [ ] 若保留原图小照片，转译部分比照片更空、更简
- [ ] 没有把照片等大重画成水彩/油画头像

### Text metaphor card

- [ ] 保留用户原句，没有改写成鸡汤标题
- [ ] 只有一个视觉隐喻，没有完整故事场景
- [ ] 没有金句叠夜景/雨窗照片，没有 PPT 图标墙

### Holiday layer

- [ ] 只用对话当天日期，窗口 ±1 天；未把拍摄日改成节日
- [ ] 是薄层而不是节日海报；符号不超过原有微图形配额
- [ ] 没有给单人照补出伴侣或节日服装
- [ ] 用户说不用节日时完全没有节日符号

### Text

- [ ] 不解释图片、不鸡汤、字数短、位置有留白  

### Final aesthetic

- [ ] 像艺术出版页  
- [ ] 不像电商图 / 模板海报 / 普通照片拼贴

## Failure Recovery

第一次结果有问题时，重试加入对应修正：

| 问题 | 修正指令要点 |
|------|----------------|
| 宫格数量/顺序错误 | 重画为精确 2×2 / 2×3 / 3×3；固定从左到右、从上到下编号 |
| 候选像换滤镜 | 重选媒介、版式、抽象度均不同的方向；至少覆盖四类视觉语言 |
| 宫格文字太多 | 删除所有风格名与说明，图内仅保留两位编号 |
| 成品像低清截图 | 弃用宫格像素，回到原始照片和选中方向重建高清 prompt |
| 转译插画太大 | 缩小至当前 40%–60%，约占九宫格一格，大幅增加空白 |
| 画面太满 | 删除至少一半非必要元素，不用新元素填空白 |
| 插画太写实 | 进一步压缩，只留轮廓/姿态/主色块/空间关系 |
| 太像手账 | 移除装饰贴纸、花边、复杂胶带、过多小图标、复古装饰 |
| 文案太鸡汤 | 更冷静、更短、更含蓄；不励志、不总结人生、不解释画面 |
| 原图被改太多 | 原图区只允许裁切/缩放/版式重组，不重设人物建筑天气场景 |
| 贴纸像手账素材包 | 删除碎贴纸与装饰，只保留主体/中景/远景；统一白边，移除厚阴影，恢复大留白 |
| 分层关系失真 | 回到原图景深；不补造被遮挡部分；减少为两层也优于错误三层 |
| 粗线插画太幼稚 | 恢复成人比例与真实动作，减少表情细节，去掉夸张眼睛和糖果色 |
| 单色块太多 | 合并相近颜色，删到 1–3 个；只有识别必需时保留第 4 个 |
| 人像被完整重画 | 删五官与皮肤纹理，只留姿态/发型/服装结构；把转译缩小到视觉岛 |
| 分层融成一张大贴纸 | 拆回 2–3 张独立白边层，拉开尺度，恢复至少 50% 留白 |
| 文本卡像金句配图 | 去掉底图照片与毛玻璃卡片，改成纸面 + 一个器物/路径隐喻 |
| 文本卡画成绘本 | 删除情节人物与场景，只留一个能解释张力的符号 |
| 节日变成海报 | 删到 1 个点缀色 + 最多 1 个符号；去掉灯笼串/圣诞老人/爱心雨 |
| 节日虚构情侣 | 去掉后加的人物与道具，回到原图人数 |

## Safety & Factual Integrity

1. 不虚构用户未提供的具体地点、时间、日期、票号、经纬度。  
2. 概念票据可用抽象编号（如 `NO. 001`），不暗示真实票据。  
3. 人物核心特征不擅自改变。  
4. 无理由不添加品牌、商标、官方印章或真实机构标识。  
5. 展览票、邮票、档案卡均为艺术化设计，不冒充官方文件。
