# Quality Checklist, Failure Recovery & Safety

---

## Quality Checklist

生成前或生成后检查：

### Composition

- [ ] 视觉中心明确  
- [ ] 留白足够  
- [ ] 版式不是机械模板  
- [ ] 原图与转译存在明确关系  

### Original image

- [ ] 原图身份和叙事未被误改  
- [ ] 裁切合理  
- [ ] 原图区域仍具摄影感  

### Translation

- [ ] 已明显简化，不是完整重画  
- [ ] 保留最重要的视觉记忆  
- [ ] 抽象程度符合参数  

### Style

- [ ] 风格准确；极简规则未被风格破坏  
- [ ] 色彩来自原图；无无关装饰  

### Layered sticker template

- [ ] 仅提取可从原图可靠识别的 2–3 层；未补造遮挡内容
- [ ] 主体、中景、远景尺度有明确层级，且没有重复主体
- [ ] 白边统一，阴影为无或极浅；整体不像贴纸包或手账
- [ ] 贴纸组未超过画面 40%，页面至少约 50% 留白

### Rounded monoline template

- [ ] 线条统一粗细、圆头圆角，无排线和多重描边
- [ ] 人物姿态、服装结构与配饰未被可爱化改写
- [ ] 色块默认 1–3 个，绝不超过 4 个；均为单色、无渐变
- [ ] 主体和色块保持视觉岛尺度，没有铺满页面

### Text

- [ ] 不解释图片、不鸡汤、字数短、位置有留白  

### Final aesthetic

- [ ] 像艺术出版页  
- [ ] 不像电商图 / 模板海报 / 普通照片拼贴

## Failure Recovery

第一次结果有问题时，重试加入对应修正：

| 问题 | 修正指令要点 |
|------|----------------|
| 转译插画太大 | 缩小至当前 40%–60%，约占九宫格一格，大幅增加空白 |
| 画面太满 | 删除至少一半非必要元素，不用新元素填空白 |
| 插画太写实 | 进一步压缩，只留轮廓/姿态/主色块/空间关系 |
| 太像手账 | 移除装饰贴纸、花边、复杂胶带、过多小图标、复古装饰 |
| 文案太鸡汤 | 更冷静、更短、更含蓄；不励志、不总结人生、不解释画面 |
| 原图被改太多 | 原图区只允许裁切/缩放/版式重组，不重设人物建筑天气场景 |
| 贴纸像手账素材包 | 删除碎贴纸与装饰，只保留主体/中景/远景；统一白边，移除厚阴影，恢复大留白 |
| 分层关系失真 | 回到原图景深；不补造被遮挡部分；减少为两层也优于错误三层 |
| 粗线插画太幼稚 | 恢复成人比例与真实动作，减少表情细节，去掉夸张眼睛和糖果色 |
| 单色块太多 | 合并相近颜色，删到 1–3 个；只有识别必需时保留第 4 个 |

## Safety & Factual Integrity

1. 不虚构用户未提供的具体地点、时间、日期、票号、经纬度。  
2. 概念票据可用抽象编号（如 `NO. 001`），不暗示真实票据。  
3. 人物核心特征不擅自改变。  
4. 无理由不添加品牌、商标、官方印章或真实机构标识。  
5. 展览票、邮票、档案卡均为艺术化设计，不冒充官方文件。
