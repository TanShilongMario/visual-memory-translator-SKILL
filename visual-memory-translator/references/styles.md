# STYLE_MODE Library

所有 Style 是「表达插件」，**不能**覆盖全局美学（极简、克制、留白、编辑感）。

---

## `minimal_watercolor` — 极简水彩

透明水彩、淡墨、轻微纸张颗粒、水迹、干/湿边、局部渗透、低密度线稿；色彩来自原图。转译主体不能成为完整风景画。

## `minimal_line_watercolor` — 极简线稿水彩

更强调线条、色彩更少、人物轮廓更清楚。适合人像与动作。

## `freehand_doodle` — 极简自由涂鸦

自由线、轻微不完美、断线、重复线、小范围马克笔/彩铅；维持高级编辑感。禁止儿童涂鸦页。

## `minimal_vector` — 现代极简矢量

几何轮廓、纯色块、3–6 色、清晰边缘、大量负空间。禁止复杂渐变与信息图式堆砌。

## `single_line_sketch` — 单线速写

单线或极少线、连续轮廓、高度概括、几乎无填色、强留白。

## `extreme_minimal_abstraction` — 极致抽象极简

信息压缩到约 5%–15%。仅保留轮廓/路径/一两个色块/光影/动作/颜色记忆。允许第一眼抽象、第二眼发现原图关系。

## `memory_color_blocks` — 色块记忆

大色块、软边界、极少线条。例：山=灰绿块，天空=蓝留白，人=深色轮廓，夕阳=暖黄点。

## `structural_deconstruction` — 结构解构

提炼建筑轮廓、透视、道路、网格、轴线。适合城市/建筑/室内/产品。

## `stamp_memory` — 邮票记忆

**把一次经历变成可以寄出的记忆。** 齿孔、小型主体、极简邮戳、日期/地点/编号。未知信息不得虚构；可用抽象编号。

## `exhibition_ticket` — 旅行展览票

**把一次经历当成一场只发生一次的展览。** 展览标题、票据结构、小图、编号、展签短句。未知地点/日期不得虚构；可用 `UNTITLED JOURNEY` / `FIELD NOTE` / `MEMORY STUDY` / `ONE-DAY EXHIBITION` 等。

## `fluted_glass` — 长虹玻璃

垂直折射、条带、模糊、拉伸；色彩分离但不艳丽；轮廓可隐约辨认。是材料介质后的记忆，不是滤镜。

## `archive_card` — 档案卡

编号、小图、简短说明、视觉标记、大量留白。禁止虚构经纬度/精确时间/真实档案号（除非用户提供）。

## `specimen_sheet` — 标本页

拆出关键元素排列。适合食物/花草/器物/细节。元素 3–7 个以内。

## `map_note` — 地图札记

路径、行进方向、道路、河流、山体。默认概念地图，非 GIS 精确（除非用户要求）。

## `commemorative_cover` — 纪念封

首日封/纪念信封语言：邮戳、日期框、小型插图。未知信息不得虚构。

## `layered_sticker_reassembly` — 分层贴纸重组

将原图按景深与叙事拆为最多三层：主体、背景 1（中景）、背景 2（远景）。各层保持摄影真实性，以统一白边贴纸形式差异化放大并重新编排。

- **适用**：主体明确、前中后景可分、人物与环境关系有叙事张力的照片。
- **比例**：主体通常最大；中景次之；远景最小或最淡。贴纸组总体约占画面 25%–40%。
- **白边**：干净暖白，宽度统一，约占各贴纸短边 2%–5%。
- **阴影**：无阴影或仅一层极浅、短距离软阴影；不得制造立体手账感。
- **重组**：允许局部重叠，但保留原图空间关系的可读线索；不得凭空补全遮挡内容。
- **留白**：至少 50%，不得用碎贴纸填空。
- **避免**：贴纸包、表情贴、彩色描边、复杂胶带、厚投影、撕纸拼贴、超过三层、重复同一主体、把多层融成一张异形大贴纸。

## `editorial_metaphor_card` — 编辑隐喻卡

把一句概念转成「短文案 + 一个视觉隐喻」。用于无参考图的文本转译。

- **结构**：原句 1–4 行 + 一个小型隐喻图形；隐喻约占 15%–30%。
- **隐喻**：一件器物、一条路径、一组量的对比；不能把句子画成完整故事。
- **色彩**：纸色 + 黑/深灰 + 一个强调色。
- **避免**：金句叠照片、毛玻璃卡片、PPT 图标、完整绘本场景、表情包。

详见 [text-visual.md](text-visual.md)。

## `banknote_specimen` — 纸币样张

纪念纸币族。上半原图铺满；下半是图录里平放的一张趋近真钞密度的虚构纪念券。

## `banknote_in_situ` — 纸币实景

纪念纸币族。上半原图铺满；下半是手持该券在同一现场取样拍照，背景为原场景略虚。

共用规则见 [banknote.md](banknote.md)。票面文字必须先读这张图再写，不要印「券 / 纪念样张」套话。只说「纸币 / 纪念钞」时按当次需求选择样张或实景，不要固定分流。

## `commemorative_banknote` — 纪念纸币（族名）

点名「纸币样张」或「纸币实景」时不要停在这个族名上，直接落到上面两个 `style_mode`。

## `rounded_monoline_blocks` — 圆润粗线色块

用单一视觉粗细的圆角线条高度概括主体，再加入少量单色色块。可爱感来自圆润转折、稳定节奏和简化比例，而不是幼态化。

- **线条**：统一粗细、圆头、圆角，优先一条连续主线或极少的断开线；不使用排线、细节纹理或多重描边。
- **主体**：保留人物姿态、动作、发型、服装结构和标志性配饰；五官最多保留 1–3 个必要记号。
- **色块**：默认 1–3 个，硬上限 4 个；每个色块为单一纯色，无渐变、阴影或纹理。色彩必须来自原图。
- **形状**：色块可位于主体后方、局部填充主体或承担环境记忆，但不得变成完整背景插画。
- **留白**：极高；主体与色块组合通常占画面 15%–30%。
- **语气**：友好、圆润、轻松，但保持成人化与编辑感。
- **避免**：儿童绘本、Q 版、表情包、过大眼睛、夸张头身比、糖果色堆叠、渐变、超过四种主色、细碎装饰。

## Future Style Extension Contract

新 Style 至少定义：

```yaml
style_id:
style_name:
concept:
medium:
line_language:
color_language:
edge_behavior:
texture:
human_rendering:
typography:
micro_graphics:
whitespace_behavior:
avoid:
```

示例：

```yaml
style_id: minimal_watercolor
style_name: 极简水彩
concept: 现实被时间稀释之后留下的透明视觉残影
medium: 透明水彩 + 少量墨线
line_language: 细、断续、低密度
color_language: 原图提取 3-6 色，低饱和
edge_behavior: 晕染、干边、自然消失
texture: 细腻水彩纸
human_rendering: 简练轮廓 + 少量淡色
typography: 自然中文手写
micro_graphics: 1-3 个极简笔记符号
whitespace_behavior: 极高
avoid: 完整水彩风景画、儿童绘本感
```
